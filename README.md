# a6du11ah.github.io

Personal site — **[a6du11ah.github.io](https://a6du11ah.github.io)**

A static page: semantic HTML, no frameworks, no build step, no runtime
dependencies. It renders with JavaScript disabled, prints to a clean
monochrome document, respects `prefers-reduced-motion`, and meets WCAG AA
contrast in both colour schemes.

```
index.html      content, in document order
assets/css/     design tokens, layout, motion, print
assets/js/      progressive enhancement only
assets/img/     favicon, social preview, portrait
```
